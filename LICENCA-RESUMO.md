# Licença do TT Note — resumo em português

> Este resumo é só para facilitar a leitura. **Vale o texto em inglês do arquivo [`LICENSE`](LICENSE).**
> O TT Note é **código aberto para ler e modificar, com restrição comercial** (*source-available*).
> Não é "open source" no sentido da OSI, porque proíbe vender.

A licença é a **MIT com a Commons Clause**.

## Você pode
- Baixar, ler, estudar e **modificar** o código.
- **Usar dentro da sua empresa**, para você e seus colegas, sem pagar nada (inclusive rodar o servidor para a equipe).
- Usar para fins pessoais, estudo e projetos sem fins lucrativos.
- **Redistribuir** o programa original ou modificado **de graça**, mantendo o aviso de copyright e este `LICENSE`.
- Publicar o seu fork, desde que mantenha o `LICENSE` (com a Commons Clause).

## Você não pode
- **Vender** o TT Note ou uma versão modificada.
- **Cobrar de clientes** por um produto ou serviço cujo valor venha, no todo ou em parte substancial, do TT Note. Isso inclui:
  - hospedar o servidor para terceiros mediante pagamento;
  - cobrar por instalação, configuração, consultoria ou suporte do TT Note;
  - embutir o TT Note num produto ou sistema que você vende.
- Remover o aviso de copyright nem a Commons Clause ao redistribuir.

## Exemplos
| Situação | Pode? |
| --- | --- |
| Uma empresa usa o TT Note e o servidor para seus funcionários | Sim |
| Você faz um fork com recursos novos e publica de graça | Sim |
| Você cobra mensalidade para hospedar o servidor do TT Note para clientes | Não |
| Você vende o TT Note modificado numa loja de aplicativos | Não |
| Você inclui o TT Note num sistema que vende para uma empresa | Não |

## Dúvida ou licença comercial
Se o seu caso não está claro ou você quer uma licença para uso comercial, fale com o autor: abra uma *issue* neste repositório.
